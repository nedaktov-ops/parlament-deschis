## 5. Method and evidence contract

Every fleet note used the same per-element record, so the seven slices could be merged without re-deriving anything ([CLICK-INVESTIGATION-JOURNEY](../50-RESEARCH/CLICK-INVESTIGATION-JOURNEY-2026-11-22.md), Phase 1; [master report](CLICK-INVESTIGATION-2026-11-22.md) §1):

- **ID** — stable within the recipe (`C01-001` … `C05-062`, `C06-008`, `C07-004`, or master IDs `B1`, `B2`).
- **file:line** — repository-relative path and exact line at HEAD `8811216`.
- **Label / i18n** — the literal or `t(key, "default")` call, with the exact ro and en definition lines quoted (`i18n.ts` ro block `:5-759`, en block `:760-1513`, default `lng: "ro"`, `fallbackLng: "en"`).
- **Purpose** — a short quote from the code comment or surrounding prose, not an inferred intention.
- **Destination / handler chain** — each hop to the terminal `navigate`, `<Link>` `to`, `href`, API call, query refetch or local state setter, with the terminal line quoted.
- **Classification** — one of `in-app route`, `external URL`, `API/download`, `state action`, `no-op`, `dead`.
- **Code quote** — a verbatim snippet of the activation line (`onClick`, `onKeyDown`, `onChange`, `href`, `to=`, `role="button"` with `activateOnKey`).
- **Verdict** — exactly one of the four allowed values below, with a code-grounded reason.
- **Improvement** — a concrete change anchored at `file:line`; where the value is data- or runtime-dependent, a named **resolver** instead of a guess.

**The four verdicts** ([master report](CLICK-INVESTIGATION-2026-11-22.md) §1):

| Verdict | Meaning |
|---|---|
