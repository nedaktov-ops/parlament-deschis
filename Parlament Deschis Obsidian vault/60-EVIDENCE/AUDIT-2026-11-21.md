## Scope and method

- **Corpus:** all **61 first-party Markdown files** in `/home/nedaktov/parlament-deschis`, processed **newest-first** (2026-11-21 → 2026-11-12).
- **Fleet:** **five fresh agents** with no prior context — disjoint date buckets plus cross-corpus pattern sweeps; the master agent independently adjudicated contradictions and corrected its own earlier errors.
- **Posture:** read-only throughout. No product code, data, workflow or GitHub state was changed by the fleet.
- **Companions:** `docs/GAP-ANALYSIS-2026-11-21.md` (vision vs. live) and `docs/AUDIT-RESOLUTIONS-2026-11-21.md` (R1–R11 adjudications). The full contradiction ledger lives in [CONTRADICTIONS](../10-STATE/CONTRADICTIONS.md).

## Resolution policy (applied in this order)

1. **Executable evidence > prose** — current source, DB queries, API responses, CI/CLI output and generated artifacts outrank any document claim.
2. **Scope before conflict** — if two numbers differ, check definitions and artifacts first; call a defect only when both describe the same thing.
3. **Newer wins on the same topic**, but an explicitly labelled historical snapshot is preserved as history, not used to override current state.
4. **Addendum > base body** within a single file (dated current-state banners).
5. **Generated artifacts derive from source** — never hand-edit `openapi.json`.
6. **No guessing** — report **NOT PROVEN** with a named resolver.

The master check found the **pinned release has no `source_license` table**, both working DBs have the table with **0 rows**, and `ensure_source_licenses()` is defined (`pipeline/licenses.py:215`) but **never called** from the CLI or app startup. Licence enforcement is therefore **latent**, not operating. Separately, **0 licence/attribution violations** were found and the required attribution string is present.
